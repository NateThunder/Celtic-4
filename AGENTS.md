# Project instructions

- Production is hosted and deployed on SiteGround.
- Production deployments are performed through GitHub; do not deploy directly from the local workspace.
- Do not push deployment changes to GitHub unless the user explicitly asks for the push.
- Do not treat Cloudflare Workers, Pages, or the `workers.dev` preview as the production deployment target unless the user explicitly requests Cloudflare.
- Before any production deployment, use the SiteGround deployment workflow and verify the live response is served by SiteGround.
